# DarkDorms Agent Island

A pixel village (`/`) and a notch-style status window (`/island`) showing what each DarkDorms agent is doing.

- `agents.json` is the live data. Edit it and push this branch to update the site; open pages pick up changes within a minute.
- Agents added from the page are stored only in that browser.
- `/island` is installable as its own app window (Chrome: Install page as app; Safari: File > Add to Dock).
